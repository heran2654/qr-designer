# QR Designer

一个低占用、纯本地运行的可视化二维码设计器。它采用“动态安全滑块”：理论参数保持完整，当前不可用范围显示为红色并禁止拖入，参数之间会实时重新计算安全边界。

## 启动

双击 `启动 QR Designer.bat`，或直接用 Chrome / Edge 打开 `index.html`。程序没有常驻服务、无需安装、不会上传二维码内容。

## 已实现

- 真实 QR Model 2 编码，支持 Unicode、L/M/Q/H、自动或固定 Version 与容量保护；
- 方形、圆形、圆角模块，模块尺寸、间距、定位点与 Logo 动态约束；
- 单色、线性/径向/角度渐变、图片纹理和透明背景；
- Logo 导入、浅色背景移除、模块级挖空、Logo-aware Mask 优化与画布直接缩放；
- Logo 间隙使用整数 module 调节，并可锁定为每侧 1 个 module；
- 模块网格、Logo 安全区、50%—200% 画布缩放；
- ZXing + jsQR 双引擎真实解码；
- 缩放、轻微模糊、对比度压力测试，不可靠时禁止导出；
- 保守的自动修复，优先保留用户的内容、颜色和整体样式；
- PNG 512—4096 预设及 256—8192 自定义尺寸；
- 矢量 SVG 导出（图片纹理自动使用 PNG 以保持效果）。

## 低占用策略

编辑器没有框架、打包器或后台进程。二维码编码器约 57 KB，jsQR 约 251 KB；ZXing 约 431 KB，并在首次验证时才加载。正常编辑只在参数停止变化后执行一次验证，避免持续占用 CPU。

OpenCV.js 的官方浏览器构建约 10.5 MB，且标准构建不包含可直接使用的 `QRCodeDetector`。本项目因此使用 ZXing + jsQR 双引擎替代，保留独立实现的二次识别，同时显著减少启动与内存成本。

## 测试

仓库包含两个 Playwright 浏览器测试：

- `tests/deep-check.mjs`：ZXing、jsQR、缩放/模糊与对比度完整导出检查。
